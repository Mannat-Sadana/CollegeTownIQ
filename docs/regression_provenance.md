# Regression Provenance — Issue A

## Current primary model

The current primary regression is generated by `src/analysis/model_affordability_access.py`.

- Input: `data/processed/college_town_analysis.gpkg`
- Current complete observations: 21
- R²: 0.028699
- Transit-distance coefficient: +$0.5175 per kilometre
- HC3 p-value: 0.98838481
- 95% confidence interval: approximately −$69.15 to +$70.19 per kilometre

These results were verified by running the current model script on October 19, 2026.

## Historical model

The historical version of `src/analysis/model_affordability_access.py`, at commit `464ea39`, used the same input path and modeled median gross rent against:

- Transit distance, converted from metres to kilometres
- Median household income, converted to $10,000 units
- Vehicle access percentage

The model used OLS with HC3 heteroskedasticity-robust standard errors.

The historical report, `docs/analysis_report_old_backup.md`, records 28 census tracts, 25 complete observations, R² approximately 0.1902, a transit-distance coefficient of approximately −$35.40 per kilometre, and p = 0.0066.

The historical accessibility sensitivity analysis also reported a 500 m result of R² = 0.1885 and p = 0.0071. The current 500 m artifact reproduces a similar, but not identical, result.

## Likely source of the discrepancy

The historical report describes tract inclusion using geographic intersection with the study area. The current pipeline applies a stricter rule requiring at least 50% of a tract's area to overlap the study area.

This change reduces the study-area dataset to 23 tracts and the complete-case regression sample to 21 observations. The changed sample is the leading explanation for the different estimates.

## Reproducibility limitation

The historical regression script is available in Git history, but the original processed input dataset was not found in the tracked repository history. The exact historical p-value of 0.0066 therefore cannot currently be independently reproduced from a verified original input file.

The historical numbers are retained only as documented historical results. They must not be presented as results from the current dataset.

## Reporting decision

The current 250 m regression is the primary reported model. The README reflects its current estimates. The historical discrepancy, model specification, likely sample-selection change, and reproduction limitation are documented here.

The 50% overlap threshold should not be changed solely to recover statistical significance. Any future comparison must identify the input dataset, tract-selection rule, complete-case sample, distance variable, and regression specification.
